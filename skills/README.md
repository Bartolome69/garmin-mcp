# Skills

Training methodology that sits on top of the Garmin tools. The server gives
Claude your data; a skill gives it a way of thinking about that data.

| Skill | What it does |
| --- | --- |
| [`half-marathon-pfitzinger`](half-marathon-pfitzinger/SKILL.md) | Plans and reviews half marathon training in Pete Pfitzinger's style — lactate threshold first, medium-long runs midweek, mesocycles with recovery weeks |

## Using one

Paste the contents of a `SKILL.md` into a conversation, or set it as a Claude
Project's custom instructions alongside the training prompt in `PROMPT.md`.

## On the source material

These encode a published coach's methodology — the reasoning, the session types,
the way a block is structured. They do not reproduce anyone's copyrighted
week-by-week schedules. If a method suits you, buy the book; Pfitzinger's
*Faster Road Racing* covers 5K through half marathon.
